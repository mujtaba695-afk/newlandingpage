## 🛠️ HOW TO USE

### **Method 1: Find & Replace (Fastest)**
1. Open `index.html` in code editor
2. Press Ctrl+H (Find & Replace)
3. Replace all {{PLACEHOLDERS}} with your content
4. Add your images
5. Test in browser

### **Method 2: Manual Edit**
1. Search for `✏️ CUSTOMIZE` comments in HTML
2. Replace content section by section
3. Update image paths
4. Save and test
